Core Minimum Viable Product

Explore the comprehensive analytical modules built right into PlanIFlow.

Visualize & Control Your Schedule Timeline

Real-time timeline rendering powered by Matplotlib and PyQt. Visualize activities, milestones, and summary task relationships with precision.

  • Standard Dependency Notation: FS, SS, FF, SF with lead & lag times
  • One-click Critical Path Highlighting (Red zero-slack tasks)
  • Interactive zoom controls (Day / Week / Month timeline scale)
  • Milestone markers and summary task progress bars

Agile Execution & Visual Workflows

Streamline team tasks with a responsive, interactive Kanban board featuring drag-and-drop card movements and multi-dimensional filtering.

  • 5 Status Columns: 📝 To Do, 🚀 In Progress, ⚠️ Delayed, 🚫 Blocked, ✅ Completed
  • Task WBS, dates, completion %, resource badges, and card notes
  • Task-level and resource-level quick filtering
  • Inline card editing dialogs for rapid updates

Monte Carlo Schedule Risk Analysis

Move beyond single-point estimates. Run up to 10,000 statistical simulations to forecast realistic project completion probabilities under uncertainty.

  • Statistical Confidence Metrics: P50, P80, and P90 completion dates
  • Identification of top risk-driver activities influencing project variance
  • Probability distribution graphs and cumulative frequency charts
  • Optimistic, Most Likely, and Pessimistic duration modeling

Earned Value Management (EVM) Metrics

Monitor project schedule and budget health using ANSI/EIA 748 standard Earned Value Management performance indices.

  • Metrics: PV (Planned Value), EV (Earned Value), AC (Actual Cost)
  • Indices: Cost Performance Index (CPI) and Schedule Performance Index (SPI)
  • Variances & Estimates: CV, SV, Estimate at Completion (EAC), Variance at Completion (VAC)
  • Plain-English health summary reports & multi-sheet Excel exports

Smart Project Health Diagnosis

An intelligent automated audit engine that synthesizes schedule logic, Monte Carlo risk findings, and EVM performance into an executive summary report.

  • Automated Schedule Health Checks (dangling tasks, excessive lag, missing predecessors)
  • Combined Schedule & Cost Variance Executive Assessment
  • Plain-English action recommendations for project managers
  • One-click status report export to PDF and Excel

Formal Security Assessment

Assessment: LOW RISK – SECURE FOR DEPLOYMENT

PlanIFlow underwent a comprehensive security audit across all core Python source files using SAST (bandit, pip-audit, xenon), manual code review, and STRIDE threat modeling.

  • Zero Cloud Telemetry: Operating 100% offline. No database server, background cloud sync, or external tracking listeners.
  • Strict DoS & Input Validation: Enforced by ProjectValidator hard limits (MAX_TASKS = 10,000, MAX_STR_LEN = 250).
  • Secure Auto-Updates: Uses TLS/HTTPS certificate verification and mandatory local SHA-256 hash checksum matching against official release records before executing installers.
  • Safe Deserialization: Strict JSON validation via jsonschema. No pickle or eval() code execution.
🛡️

STRIDE Threat Modeling Summary

Threat Category Potential Scenario Mitigation Strategy Status
Spoofing Impersonating GitHub update server HTTPS/TLS certificate validation enforced via Requests library ✅ Mitigated
Tampering Manipulating local JSON project files ProjectValidator schema validation & string sanitization. No macro execution. ✅ Mitigated
Tampering Modifying installer binary in transit Local SHA-256 hash calculation compared against trusted release .sha256.txt ✅ Mitigated
Information Disclosure Leaking sensitive data in crash reports Sanitized UI exception handlers. Zero automatic crash reporting or telemetry. ✅ Mitigated
Denial of Service Importing massive file to exhaust RAM Hard resource limits (MAX_TASKS = 10,000, string length caps) prevent memory exhaustion. ✅ Mitigated

🔐 Windows Code Verification Certificate Guide

To verify digital signatures on Windows, download the Code Verification Certificate by Dipta Roy and trust it locally:

  1. Download and extract Signed_By_Dipta_CodeSigningPublicKey.cer.
  2. Right-click the certificate → Install Certificate → Select Local Machine.
  3. Choose "Place all certificates in the following store" → Browse → Select Trusted Root Certification Authorities.
  4. Complete the wizard. Right-click PlanIFlow_2.8.0.msi → Properties → Digital Signatures tab to confirm: "This digital signature is OK."
